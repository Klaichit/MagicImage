# 24sEnergy Social Gallery

ชุดภาพประกอบโพสต์ Facebook ของ 24sEnergy ปรับจากต้นฉบับใน Google Drive ให้สอดคล้องกับเนื้อหาและแนวทางแบรนด์

## เปิดแกลเลอรีออนไลน์

[https://klaichit.github.io/MagicImage/](https://klaichit.github.io/MagicImage/)

หน้าเว็บอยู่ในโฟลเดอร์ `dist/` และเผยแพร่อัตโนมัติด้วย GitHub Pages เมื่อมีการ push เข้า branch `main`

## แนวทางภาพ

- สีหลัก: Purple `#6A2DAF`, Charcoal `#3F3F3F`, White และ Soft Lavender `#F1E9FB`
- ภาพถ่ายแนวเทคนิคและอุตสาหกรรม: Solar PV, BESS, EV Charging และการวิเคราะห์พลังงาน
- รักษาพาดหัว ตัวเลข วันที่ แหล่งอ้างอิง และ CTA จากต้นฉบับ
- ข่าวโครงการภายนอกที่ใช้ภาพสร้างใหม่ระบุว่า `ภาพจำลองประกอบเนื้อหา`
- ใช้โลโก้ 24sEnergy ตามสัดส่วนเดิม
